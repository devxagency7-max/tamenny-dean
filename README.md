# طَمّني — منصة وب عميد كلية الصيدلة (Faculty Dean Observability Web Portal)

منصة ويب متكاملة وعالية الدقة مخصصة لـ **عميد كلية الصيدلة (`FacultyDean`)** لمتابعة وتدقيق أنشطة تدريب طلاب الكلية الميداني بمراكز التدريب المعتمدة ضمن منظومة **طَمّني (Tamenny Healthcare Ecosystem)**.

تم بناء وتصميم المنصة بالالتزام الحرفي بكافة معايير ونظام التصميم الموثق في [DESIGN_SYSTEM.md](../DESIGN_SYSTEM.md).

---

## 1. نموذج العمل (Observability Model)

* **رصد ومتابعة آنية (Read-Only Observability):**  
  يستعرض العميد بيانات طلاب كليته، العمليات التي قاموا بها بالصيدليات (فحص الروشتات، صياغة خطط الأدوية، صرف الطلبات)، وساعات الحضور الموثقة.
* **بدون تعطيل مسار العمل (No Approval Bottleneck):**  
  العميد **لا يوافق** على أي عملية تشغيلية ولا يتدخل بين المتدرب والصيدلية؛ المتدرب يمارس عمله بصلاحيات كاملة مماثلة للصيدلي، بينما المنصة توفر مرصداً أكاديمياً رقابياً لإدارة الكلية.
* **عزل الكليات (Multi-Tenant Faculty Scoping):**  
  لا تظهر في اللوحة سوى بيانات المتدربين التابعين لكلية العميد فقط (مثال: كلية الصيدلة - جامعة القاهرة).

---

## 2. المكونات والميزات الرئيسية

1. **الرئيسية المباشرة (Search-First Dashboard):**
   * شريط بحث فوري ذكي مع اختصار `⌘K` وفلاتر سريعة (الكل، نشط، مكتمل، متابعة).
   * مؤشرات إنجاز رئيسية (المتدربون، العمليات، استشارات الشات).
   * جدول سريع للوصول الفوري لملفات الطلاب والعمليات المنفذة.
   * بث حي للعمليات الميدانية لحظة بلحظة.

2. **صفحة الملف الطبي للمتدرب (Full-Page Intern Dossier):**
   * صفحة كاملة مستقلة (ليست نافذة منبثقة Modal) تفتح بنقرة واحدة، وتتضمن:
     * **استشارات ومحادثات المرضى (Live Patient Chat Observability):** قراءة حية لرسائل الشات بين المتدرب والمرضى لتقييم مهارات التواصل الطبي والجرعات.
     * **الروشتات المفحوصة:** تشخيص الطبيب، الأدوية، والتوصيات الطبية للمتدرب مع توثيق المشرف.
     * **خطط العلاج:** جداول مواعيد الأدوية وتنظيم الجرعات.
     * **صرف الطلبات:** سجل تجهيز وتسليم الأدوية.

3. **سجل المتدربين والبحث الشامل (Interns Directory):**
   * كشف شامل بجميع المتدربين مع الحالات والعمليات المنفذة.

4. **ملف الكلية وتصدير التقارير (Faculty Profile & Export):**
   * بيانات الكلية الأكاديمية (جامعة القاهرة).
   * طباعة كشوف الدرجات والملف الطبي للمتدرب (PDF).

5. **دعم كامل للوضعين واللغتين:**
   * الوضع الليلي والفاتح (Dark / Light Mode) مع حفظ التفضيل.
   * دعم الاتجاهين RTL (العربية) و LTR (الإنجليزية).

## 3. طريقة التشغيل محلياً (How to Run)

### الخيار 1: باستخدام Node.js
```bash
cd /Users/devx/Documents/tameny/faculty_dean
npm start
# أو
npx serve . -l 3000
```
افتح المتصفح على الرابط: `http://localhost:3000`

### الخيار 2: باستخدام Python (سيرفر فوري بدون أي تثبيت)
```bash
cd /Users/devx/Documents/tameny/faculty_dean
python3 -m http.server 3000
```
افتح المتصفح على الرابط: `http://localhost:3000`

### الخيار 3: الفتح المباشر
يمكنك فتح ملف `index.html` مباشرة في أي متصفح ويب حديث.
